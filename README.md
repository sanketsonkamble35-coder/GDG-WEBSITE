# 🧙 Fantasy Character Creator
A fantasy-themed interactive web application that allows users to generate unique fantasy characters, view AI-generated portraits, create character backstories, and save their favourite characters to a personal deck.

## ✨ Features
- **Generate Character:** Create random fantasy characters with unique names and classes.
- **AI Character Portraits:** Generate and regenerate fantasy-style character portraits.
- **Character Backstory:** Generate unique origin stories for each character.
- **Character Stats:** Display randomly generated Health, Mana, and Strength.
- **Save to Deck:** Save favourite characters with their details and stats.
- **My Deck:** View your collection of saved fantasy characters.
- **Fantasy UI:** Ancient alchemist's workbench-inspired design.

## 🛠️ Tech Stack
- React
- TypeScript
- Vite
- Tailwind CSS
- Google Gemini API
- Lucide React
- Motion

## 📁 Installation and Setup

### 1. Clone the repository
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```
### 2. Navigate to the project directory
```bash
cd fantasy-character-creator
```
### 3. Install dependencies
```bash
npm install
```
### 4. Start the development server
```bash
npm run dev
```
### 5. Open in browser
Visit:
```text
http://localhost:3000
```

## 🏗️ Build for Production
```bash
npm run build
```

## 🔐 API Configuration
Some AI-powered features require a valid Google Gemini API key.
Configure your API key using the environment variable expected by the application. Keep API keys private and never commit them to GitHub.
